# Security Policy

## Supported versions

The latest 0.x release on npm is the supported line.

## What this library does not do

Phone numbers stay on the device. The library does not log, persist, or send numbers to a server. A selected number is a hint, not proof of possession — verify it with your own OTP or equivalent flow.

## Reporting a vulnerability

Email **vikramjangid203@gmail.com**. Do not open a public GitHub issue for security reports.

Please include the package version, React Native version, and steps to reproduce. You will get a response within 7 days.
